# Backend - Optilog

## ✅ Instalar dependências
`npm install`

## ✅ Rodar servidor
`npm run start`

- ou

`node app.js`

## ✅ Arquivo .env necessário
Copie `.env.local.example` e renomeie para `.env`.

## ✅ Endpoint de teste
GET `/health`
`http://localhost:3001/health`

- Dica: a porta padrão é `3001` (via `PORT`). Se a porta estiver em uso, defina outra (ex.: `3011`).
